01. 처음 시작하기

  1. 위 버튼으로 EXE를 다운로드하고 실행합니다. Windows 보안 경고가 뜨면 배포 출처와 파일 해시를 확인하고 실행 여부를 결정하세요.
  2. EXAONE API 플랫폼에서 본인의 API 키를 준비합니다.
  3. 앱 왼쪽 아래 API 키 설정에서 키를 저장합니다. 배포 파일에는 API 키가 포함되어 있지 않습니다.
  4. 작업 폴더 선택으로 사용할 프로젝트 또는 문서 폴더를 지정합니다.
  5. “현재 작업 폴더의 파일 목록을 보여줘”처럼 첫 요청을 입력합니다.

생각의 깊이는 빠르게 / 균형 있게 / 깊게 중 선택합니다. 실제 명령에 필요한 Python·Node.js 등은 파일·환경·예약 관리 → 실행 환경에서 확인할 수 있습니다.

02. 대화와 요청 대기열

Enter로 전송하고 Shift+Enter로 줄바꿈합니다. 응답은 생성되는 대로 표시됩니다. 각 API 요청의 대기 시간은 최대 30분이며 서버·네트워크 상황에 따라 먼저 종료될 수 있습니다.

응답 중 새 텍스트를 보내면 대기열에 추가됩니다(최대 10개). 현재 작업이 끝난 뒤 앞선 답변을 포함해 순서대로 처리합니다. 여러 요청을 동시에 추론하거나 현재 추론에 끼워 넣는 방식은 아닙니다.

대기 항목은 개별 취소할 수 있습니다. 중지·오류·앱 재시작 이후에는 남은 대기열을 직접 재개하세요. 첨부는 현재 작업이 끝난 뒤 추가합니다.

03. 파일 첨부·검색·편집

＋ 파일 첨부로 PDF, DOCX, 텍스트·코드 파일을 추가합니다. 최대 5개, 파일당 10MB이며 추출 텍스트 합계는 최대 12만 자입니다. PDF는 최대 100페이지를 분석하며 이미지 스캔 문서의 OCR은 지원하지 않습니다.

첨부 내용은 다음 요청에 함께 전송됩니다. “첨부 문서의 결정 사항을 정리해줘”, “프로젝트에서 로그인 함수를 찾아줘”처럼 요청하세요. 웹 검색 결과에는 출처 링크가 표시되며 검색 서비스 사정에 따라 제한될 수 있습니다.

파일 저장 전 변경 내용을 확인하고 승인합니다. 파일·환경·예약 관리 → 파일 복원에서 백업을 확인할 수 있습니다. 백업 후 다른 변경이 생긴 파일은 덮어쓰기 충돌 방지를 위해 복원이 제한됩니다.

04. 명령 실행과 PowerShell 터미널

AI에 실행을 요청하면 명령과 작업 폴더를 보여주고 승인을 받습니다. 이 유형의 명령은 다음부터 자동 승인을 선택하면 허용된 규칙에 맞는 명령만 확인을 생략합니다. 자동 승인 관리에서 규칙을 삭제할 수 있습니다.

PowerShell 터미널은 직접 입력한 명령을 별도 승인 없이 실행합니다. 같은 터미널에서 현재 폴더·변수·가상환경 상태가 유지되며, 초기화·중지·앱 종료·작업 폴더 변경 시 초기화됩니다. 대화형 입력이나 전체 화면 터미널 프로그램은 지원하지 않습니다.

명령은 일반 Windows 사용자 권한으로 실행됩니다. 작업 폴더 밖이나 네트워크에도 영향을 줄 수 있으며, 파일 복원은 모든 시스템 변경을 되돌리는 기능이 아닙니다. 명령 실행은 최대 5분, 출력은 최대 64,000자로 제한됩니다.

05. 기록 저장·맥락 압축·복원

대화·작업 기록에서 이전 대화를 이어갈 수 있습니다. API에 보내는 대화가 기본 50,000자를 넘고 요약할 이전 대화가 있을 때 오래된 부분을 요약합니다. 최근 대화는 유지하고, 이미 압축한 내용은 재사용합니다. 원본 기록은 로컬에 남습니다.

압축 기준은 20,000 / 30,000 / 50,000 / 60,000자로 변경하거나 끌 수 있습니다. 문자 수는 토큰 수와 다릅니다. 요약도 API를 사용하며 세부 정보가 생략될 수 있으므로 중요한 조건은 다시 명시하세요.

대화·첨부 추출문·도구 결과·백업·대기열 등은 %APPDATA%\exaone-agent\workspace.json에 평문으로 저장됩니다. API 키는 settings.json에 Windows 암호화를 이용해 별도로 저장됩니다. 대화와 첨부, AI 도구 결과는 응답 생성을 위해 EXAONE API로 전송됩니다.

대화 삭제가 파일 백업까지 지우지는 않습니다. API 사용량 표시는 호출에서 보고된 토큰 사용량이며 계정의 남은 잔액을 뜻하지 않습니다.

06. 예약 작업과 알림

파일·환경·예약 관리 → 예약·알림에서 최소 5분 간격의 반복 작업 또는 매일 정해진 시간의 작업을 등록합니다. 앱이 실행 중이어야 예약 작업이 동작합니다. PC가 꺼져 있거나 앱이 종료되어 있으면 실행하지 않습니다.

다른 작업이나 대기열이 처리 중이면 기다립니다. 결과는 별도 작업 기록에서 확인할 수 있으며, 필요한 실행 승인은 예약 작업에서도 요청합니다. 알림이 보이지 않으면 Windows 알림 설정을 확인하세요.

07. 문제가 생겼을 때

응답이 늦거나 시간 초과가 발생해요

깊은 추론, 긴 대화, API 혼잡으로 오래 걸릴 수 있습니다. 상태 표시를 확인하고 필요하면 중지하세요. 맥락 압축을 켜거나 새 대화에서 요청을 줄여 다시 시도할 수 있습니다. 중지한 요청도 서버에서 처리되어 요금이 발생할 수 있습니다.

API 키 오류·요청 제한이 나와요

API 키 설정을 다시 확인하고 EXAONE 플랫폼에서 이용 권한·사용량·결제 상태를 확인하세요. 인증 실패, 요청 제한, 서버 오류는 서로 다른 원인입니다. 응답이 없다는 이유만으로 토큰 소진으로 판단할 수 없습니다.

명령 실행이 실패했어요

작업 폴더와 실행 환경을 확인하고, 표시되는 종료 코드·오류 출력을 살펴보세요. 오류 분석 후 이어가기를 사용해 원인을 분석할 수 있습니다. 이미 실행한 작업의 결과를 확인한 뒤 재시도하세요.

업데이트 또는 삭제는 어떻게 하나요?

앱을 종료하고 최신 EXE를 실행하세요. 같은 Windows 사용자 환경의 기록은 기존 저장 경로를 사용합니다. EXE 삭제만으로 기록과 API 키가 삭제되지는 않으며, 완전히 지우려면 필요한 백업을 보관한 뒤 앱 데이터 폴더를 별도로 정리하세요.
