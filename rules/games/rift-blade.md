# 균열의 검

- `/arcade/rift-blade.html`: 독립 Canvas 2D 횡스크롤 액션 RPG. 외부 게임 엔진·이미지 다운로드 없이 실행.
- 6개 던전, 각 일반 웨이브와 수문장 웨이브로 총 12개 전투. 잿빛 성문 → 심연의 회랑 → 붉은 왕좌 → 독안개 숲 → 서리 감옥 → 균열의 심장 순서. `RIFT_STAGES`에 이름·색·보스·지역 설명·공략 힌트·적 구성을 함께 정의.
- 검병·마법사 외에 중갑병(피해 22% 감소·강타), 궁병(거리 유지·조준 화살·후반 3연사), 망령(빠른 이동·예고 돌진) 추가. 보스는 원형 강타, 연속 마법진, 십자 불길, 독꽃, 빙결선, 연쇄 균열로 서로 다른 지면 공격 사용.
- `hazards`의 타원 범위는 최소 0.75초 경고 후 1회 피해 판정. `wind/maxWind`로 경고 진행, `life`로 발동 잔상을 표현하며 전투 이외 상태에서 정지하고 웨이브 전환 시 초기화. 투사체는 방향 벡터·종류·색·피해를 보유.
- 입장 전 검사·마법사·격투가·궁수·암살자·성기사 중 선택. 직업마다 체력·마력·이동 속도와 사거리, 공격 속도가 다름. 각 직업의 기본 공격·K/L 스킬·E 전용 스킬·U 궁극기 총 5종, 전체 30개 기술.
- WASD/방향키 이동, J 3단 공격(누르기 유지 가능), K 전방 스킬, L 범위 스킬, E 전용 스킬, U 궁극기, Space 무적 대시, H 물약, P/Esc 일시정지. 모바일 멀티터치 이동·공격. E는 레벨 2, U는 레벨 3 또는 숙련 노드 1랭크부터 사용, U의 기본 마력 소모는 65.
- E의 실제 효과: 검사 4초 피해 65% 감소 보호막, 마법사 주변 적 3초 둔화(이동·공격 진행 45% 속도), 격투가 5초 이동 35% 증가·기본 공격 대기 38% 감소, 궁수 전방 3연속 명중, 암살자 전방 105 순간이동·0.45초 무적·급습 피해, 성기사 체력 45 회복·3초 보호막. 타이머는 전투 상태에서만 감소.
- 레벨 경험치 요구량은 `30 + level × 20` (레벨 2까지 50, 다음 70)이며 초과 경험치 이월. 레벨업마다 공격력 +4·최대 체력 +15·체력/마력 일부 회복·SP 2 및 성장 선택권 1 지급. 처음부터 SP 1 보유. 성장 선택권으로 공격력 +3 / 최대 체력 +15 / 최대 마력 +10과 초당 마력 회복 +1 중 선택. 선택권 누적·1회 소비 보장, 전투·일시정지·스킬트리 상태에서만 소비 가능.
- 스킬트리를 열면 `talents` 상태로 전투·효과·쿨타임 정지. 무력(power): 랭크당 공격력 +5, 흐름(flow): 최대 마력 +10·초당 회복 +2·쿨타임 8% 감소, 수호(guard): 최대 체력 +25·받는 피해 6% 감소, 숙련(mastery): 스킬 피해 15% 증가·궁극기 해금. 각 노드 최대 3랭크. 숙련은 다른 노드에 총 2포인트 투자 후 해금. 포인트 소비는 해당 상태에서만 허용.
- 위 공통 노드 외에 직업별 전문화 6개(전투·집중·생존 3갈래, 각 2단계), 전체 36개. `RIFT_BRANCHES[classId]`와 `branchRanks`로 관리. 1단계는 레벨 2, 2단계는 레벨 4와 이전 단계 필요. 각 1SP·최대 1랭크. 사거리, 기본/스킬 피해, 마력 소모, 회복, 흡혈, 둔화, 이동, 대시 보호막·무적시간, 피해 감소가 실제 전투에 반영됨. 습득은 `talents` 상태 한정.
- 레벨 5부터 원정당 1회 전직 선택. 각 직업 2개, 총 12전직: 광전사/검의 수호자, 빙결술사/화염술사, 질풍권사/금강투사, 신궁/바람추적자, 밤의 처형자/혈영 추적자, 빛의 성인/천벌의 심판관. 선택은 스킬트리 상태에서만 가능하고 SP 소모 없음. 전직별 피해·흡혈·둔화·방어·체력·마력·사거리·기본 2연사 등이 실제로 달라짐. `RIFT_SPECIALIZATIONS`, `specializationId`, `specialization`으로 관리하며 중복 선택·효과 중첩 방지.
- 전직 시 R 각성기 해금. 전직마다 다른 이름·사거리·다중 타격·회복·보호막·둔화·가속을 제공하는 12개 각성기 추가. 기본 30기술과 합계 42개. 기본 소모 75~80 MP, 재사용 17~20초. `getSkill('awakening')`은 전직 전에도 잠금 안내용 객체를 반환하되 실행은 `awakeningUnlocked`로 차단.
- 기술 강화는 K/L/E/U/R 별도 0~3랭크. 스킬트리에서 랭크당 1SP, 1랭크 레벨 2 / 2랭크 레벨 4 / 3랭크 레벨 6 요구. E/U/R의 기존 해금 조건도 함께 확인. 랭크마다 피해 15% 증가, 마력 소모 5% 감소. E 보호막·가속·둔화 지속시간도 랭크당 1초 증가하고 성기사 E 회복은 10 증가. 각성기의 보호막·가속은 랭크당 1초, 치유는 15 증가. `skillRanks`, `skillRankStatus`, `upgradeSkill` 사용.
- 표시용 실제 수치: `effectiveDamage`(기본 공격력), `effectiveRange(name)`, `damageMultiplier(name)`, `damageReduction`(0~1 비율), `regenRate`(초당 마력), `skillCost(name)`, `skillCooldown(name)`. 전직·전문화·공통 노드·기술 랭크를 모두 반영.
- 던전 사이에는 아직 얻지 않은 유물 중 무작위 3개를 제시하고 하나를 선택. `RIFT_RELICS` 9종: 검의 맹세·수호의 맹세·심연의 맹세·바람의 장화·붉은 이빨·별빛 렌즈·마력의 샘·고대 수호석·순환의 인장. 공격력·최대 자원·이동/대시·흡혈·사거리·회복·방어·마력 효율을 조합. `relics`와 `upgradeOptions`는 ID 배열이며 제시되지 않은 유물·중복 선택 차단. 유물 획득 시 체력 40·마력 전체·물약 1개(최대 5) 보급. 6개 던전 클리어 또는 체력 소진 시 결과 화면.
- 성장은 해당 원정 동안 유지되며 승리·패배 뒤 새 원정을 시작하면 초기화. 최고 점수 `riftBladeBest`, 원정 체크포인트 `riftBladeRunV1`, 효과음·연출 설정 `riftBladeSettings`를 같은 브라우저 localStorage에 저장. 온라인 랭킹 없음.
- 순수 규칙 `scripts/rift-core.js`, Canvas 표현·입력 `scripts/rift-blade.js`, 스타일 `styles/rift-blade.css`.
- 그래픽은 직업별 체형·곡선 갑옷·얼굴·손·옷자락과 관절 동작이 있는 확대 캐릭터, 단계별 대형 보스 장식으로 구성. 성문 조각상·회랑 스테인드글라스·왕좌 휘장 외에 독안개 숲의 거목·발광 버섯, 서리 감옥의 얼음 기둥·사슬, 균열의 심장의 용암 수로·공중 균열로 6개 지역을 구분. 신규 보스 가시의 여왕·빙결 거인·균열 포식자와 신규 병종의 무기·체형·장비 차별화. 정적 배경은 던전별 Canvas 캐시, 화면은 1.5~2배 해상도로 렌더링.
- 검격 면·마력 광선·화살 잔상·타격 불꽃과 외곽선 피해 숫자로 전투 가독성 강화. 사망 시 적의 외형을 복사하여 기울어 쓰러지고 먼지와 함께 사라짐. 배경·공격·사망·레벨업 연출은 게임 시간과 효과 수명 기반으로 정지 상태에서 함께 멈춤.
- 창 전환·포커스 이탈 시 자동 일시정지, 입력 해제. 일시정지·강화·결과 화면에서는 전투 시간 정지.
- 검증: `node scripts/test-rift-blade.cjs`, Playwright 설치 경로를 NODE_PATH로 지정 후 `node scripts/test-rift-blade-browser.cjs`.

## 추가 고도화 10회

1. **난이도**: 탐험(적 HP 80%·피해 65%·전투 점수 85%), 일반(기존 수치), 숙련(적 HP/피해 135%·점수 140%). 시작 전 선택, 원정 중 변경 금지. `RIFT_DIFFICULTIES`, 생성자 세 번째 인수 `{difficulty}`, `setDifficulty`.
2. **정밀 회피**: 대시 시작 0.12초 내 실제 공격을 무적으로 차단할 때 대시당 한 번 MP 12·점수 50. `perfectWindow/perfectUsed`; 실제 피해량·최대 콤보·정밀 회피 등 `stats` 추적.
3. **정예 적**: 두 번째 지역부터 각 웨이브 한 명, HP 1.4배. 질풍은 이동 1.45배, 철갑은 추가 피해 20% 감소, 흡혈은 실제 준 피해의 40% 회복. 근접·투사체·지면 공격의 `sourceId`로 공격자 식별. 정예 처치 통계와 표시 추가.
4. **보스 2페이즈**: 생존 중 HP 45% 이하에서 한 번 격노. 공격 간격 2.2→1.35초, 회피 가능한 예고 공격 두 개 추가. 이름·체력바·PHASE II 표시.
5. **전리품**: 골드·체력·마력 드롭, 42px 근접 자동 획득, 20초 수명. 자원 상한·중복 획득 방지. 마지막 적 처치 시 남은 전리품 자동 회수. `coins/pickups/pickupSerial`, `stats.goldEarned`.
6. **휴식 보급소**: 치료 70G(HP 80), 물약 55G(1개·최대 5), 훈련 100G(원정 공격력 +3). 각 상품 휴식당 한 번. 60G로 유물 후보 갱신 한 번, 적어도 하나가 다른 후보. `shopOffers`, `buy`, `rerollRelics`, `shopPurchases`, `rerollsRemaining`.
7. **유물 시너지**: 검의 맹세+붉은 이빨=혈검(공격 +5·흡혈 +3%), 심연의 맹세+순환의 인장=비전(마력 회복 +2·재사용 −8%), 수호의 맹세+고대 수호석=철벽(추가 피해 감소 8%·대시 보호막 0.8초). `RIFT_SYNERGIES/activeSynergies`는 현재 소유에서 계산하여 중복 누적 없음. 후보 카드에 조합 완성 안내.
8. **지역 임무**: 1/4지역 무피해, 2/5지역 85/100초 돌파, 3/6지역 16/22콤보. 두 웨이브 동안 유지하고 지역 완료 시 `80 + stage × 15` 골드 한 번 지급. 실패해도 진행 가능, 중단 상태에서 시간 정지. `objective`에 진행·성공·실패·지급 상태 기록.
9. **효과음·연출 설정**: `RiftAudio`가 Web Audio로 공격·명중·피격·레벨업·보스·유물 효과음을 합성. 기본 음소거, 사용자 입력 후만 오디오 시작. 중단/음소거 재생 누적 방지, 동시 음원 제한·정리. 연출 줄이기는 배경 움직임과 부가 스킬 입자·CSS 모션을 줄이며 전투 예고는 유지.
10. **저장·이어하기와 결과**: `RiftSave`가 버전·허용 필드·범위·데이터 크기를 검증. 15초 및 상태 전환 자동 저장, 수동 저장하고 쉬기·페이지 종료 저장. 재방문은 이어하기 버튼으로 일시정지 상태 복원(보급소는 그대로). 승리/패배 시 체크포인트 제거. 같은 브라우저에서만 사용. 결과에는 지역·콤보·회피·정예·골드·시간 표시.

- 1~8회차는 각각 코어 회귀 테스트에 독립 검증 구간을 추가하고 통과. 9회차: `node scripts/test-rift-audio.cjs`. 10회차: `node scripts/test-rift-save.cjs`.
- 실제 UI 통합 검증: `node scripts/test-rift-advanced-browser.cjs`. 난이도 선택·상점·재추첨·세트·실제 AudioContext·설정 보존·저장 후 새로고침/이어하기·모바일 배치·결과 통계 확인. 기존 원정 브라우저 테스트도 통과. `RIFT_TEST_RESULTS` 환경 변수로 기존 회귀 테스트의 캡처 폴더를 분리 가능.
