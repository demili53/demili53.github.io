# 운빨좆망겜 (arcade/fog-front.html)

2026-11-20 태민의 기획안(이미지 2장, "정찰 타워 디펜스")으로 새로 만든 게임. 자체 Canvas 2D, 외부 라이브러리 없음. 그림은 모두 코드로 그린 오리지널(기획안의 곰·벌·개 그림은 자리표시였음).

## 파일
- `arcade/fog-front.html`: 페이지, 인라인 스타일, HUD(인구·스테이지·보스 정보·자원 1·2), 메뉴·정지·결과 오버레이, 가위바위보 창, 영웅별 스킬 6칸, 소환·강화·수리·바로 시작 버튼.
- `scripts/fog-core.js`: 순수 규칙(DOM 없음, Node에서 require). `FogGame`이 상태를 갖고 화면은 `drainEvents()`로 연출 이벤트를 받는다. 상대 AI(`aiThink`)도 여기 있다.
- `scripts/fog-art.js`: 영웅 6종·몬스터 8종·보스 4종·아이콘·타일·본부·안개 조각을 오프스크린 캔버스에 한 번 그려 캐시.
- `scripts/fog-front.js`: 루프, 끌어서 놓기, 렌더링(흐르는 안개 마스크, 조명 맵, 파티클), HUD, 메뉴, 효과음(Web Audio, 기본 꺼짐).
- 테스트: `scripts/test-fog-front.cjs`(규칙), `scripts/test-fog-front-browser.cjs`(Playwright).

## 기획안 그대로 옮긴 것
- 위 상대 보드, 아래 내 보드(각 7×5칸), 보드마다 START 칸과 본부(체력 20/20), 회색 안개 칸.
- 몬스터 출현 지점은 두 보드 사이 왼쪽. 홀수 스테이지는 오른쪽으로 돌아 위 상대 본부로, 짝수 스테이지는 아래 내 본부로(빨간 화살표).
- 본부가 무너지면 그쪽으로 가던 몬스터는 왼쪽 길(파란 점선)을 따라 다른 본부로 간다.
- 끌어서 놓기로 정찰, 정찰 중엔 싸우지 못함. 정찰 시간은 인구 1 = 10초, 2 = 8초, 3 = 5초, 4 = 4초.
- 안개 속 몬스터 둥지: 정찰 실패(정찰병 소멸), 위치만 드러남. 사거리가 닿는 영웅이 자동 공격, 토벌하면 큰 보상, 오래 걸림.
- 안개 속 동료: 가위바위보. 이기면 영웅 합류, 지면 없음.
- 인구 0/20, 스테이지, 보스 정보 초상, 자원 1·2 HUD. 아래 영웅별 스킬 버튼 6개. 상대 보드는 AI.

## 빈칸을 채운 결정
- 자원 1 = 수정(소환, 처치·정산 수입), 자원 2 = 광석(강화 +15%씩, 본부 수리 +4).
- 영웅 6종: 정찰병(인구1), 궁수(1), 창기사(2, 둔화), 화염술사(2, 범위), 뇌전술사(3, 연쇄), 수호자(4, 주변 공격력 오라). 소환은 무작위(인구가 넘치는 영웅은 안 나옴), 소환 비용 45에서 5씩 올라 최대 130.
- 스킬 6칸 = 영웅 종류별 스킬. 그 영웅이 보드에 있어야 쓸 수 있음(신호탄: 안개 3칸 엿보기, 화살비, 대지 울림, 불꽃 장벽, 낙뢰, 성역).
- 정찰은 밝혀진 칸과 맞닿은(상하좌우) 안개 칸만. 시작은 START 포함 3칸이 밝혀져 있고 영웅 2명(궁수·정찰병).
- 안개 내용물(양쪽 보드 동일 배치, 상하 반전): 둥지 5(START에서 멀수록 큰 둥지), 수정 5, 광석 4, 동료 4, 보물 상자 1, 고대 제단 1, 덫 1, 나머지 빈 땅.
- 동료 가위바위보: 10초 안에 고르지 않으면 무작위. 비기면 다시(세 번째 비김은 패배).
- 상대 본부가 무너져도 게임은 계속된다(보상 수정 +200, 점수 +3000). 대신 홀수 스테이지 몬스터도 왼쪽 길로 내려온다. 내 본부가 무너지면 패배, 20스테이지를 버티면 승리.
- 상대 수준 3단계: 쉬움·보통·강함은 상대 AI 판단 속도와 몬스터 체력(×0.8/1/1.12)을 함께 바꾼다.

## 개선 5회차 기록
1. 그래픽·이펙트: 반해상도 조명 맵(영웅·본부·투사체 주변만 밝음), 흐린 마스크로 자르는 두 겹 흐르는 안개, 안개 걷힘 연출, 투사체 궤적, 처치 자국, 본부 연기·불, 반딧불, 공격 반동.
2. 다양성: 몬스터 5종 추가(분열 젤리, 치유 나방, 그림자 박쥐(둔화 반감), 방패 거북(주변 방어 오라)), 보스 고유 패턴(진흙 거인 분열, 안개 여왕 재안개·나방 소환, 강철 딱정왕 경화, 심연의 눈 시선 기절·박쥐), 제단·덫, 스테이지 테마 웨이브, 둥지 체력 재생.
3. 고도화: 같은 영웅·같은 별 합성(최대 3성, 인구·칸이 빔), 스테이지 날씨 6종, 정산 이자(남은 수정 8%, 최대 30), 8스테이지부터 정예 몬스터, 상대 성향 3종(공격형·수비형·성장형).
4. 연출: 보스 등장 카드, 보스 처치 슬로모션, 2배속(F), 첫 판 안내 3단계, 승리 색종이, 결과에 상대 운명 표시.
5. 다듬기: 자동 대전 시뮬레이션으로 보스 체력 고정값·체력 곡선 조정(보통에서 봇 승률 약 절반), 화면 높이에 맞춘 열 너비, 모바일 배치, 규칙·브라우저 테스트.

## 조작
- 끌어서 놓기(마우스·터치). 영웅을 누른 뒤 칸을 눌러도 된다. 안개 칸 = 정찰, 빈 칸 = 이동, 같은 영웅·같은 별 = 합성, 다른 영웅 = 자리 바꾸기.
- 키보드: 1~6 스킬, Q 소환, W 강화, E 수리, Space 바로 시작, F 배속, P/Esc 정지.
- localStorage: `fogFrontBest`(최고 점수), `fogFrontLevel`, `fogFrontSound`, `fogFrontTutorial`. 온라인 순위 없음.
