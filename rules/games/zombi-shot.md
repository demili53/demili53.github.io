## 좀비 슈팅 게임 기획 가이드

- 버전: `2026-08-24`
- 권장 경로: `/arcade/zombi-shot.html`
- 상위 규칙: [make-game.md](../make-game.md)를 따른다.

1. **핵심 게임 규칙**
   - 장르는 화면 아래의 군인이 위에서 내려오는 좀비를 막는 세로형 슈팅 게임이다.
   - 군인은 화면 아래쪽에 고정되며 **좌우로만 이동**할 수 있다. 위아래 이동은 제공하지 않는다.
   - 좀비는 화면 위쪽에서 생성되어 화면 아래쪽을 향해 계속 내려온다.
   - 러닝머신처럼 도로 배경이 위에서 아래로 끊임없이 흐르며 군인은 화면 아래 위치를 유지한다.
   - 좀비와 군인이 직접 닿을 때만 즉시 게임오버다. 군인과 충돌하지 않고 화면 아래로 지나간 좀비는 화면 밖에서 정리한다.
   - 모든 좀비는 머리 위에 현재 체력을 숫자로 표시하며, 피해를 받을 때마다 남은 체력 숫자를 즉시 줄인다.
   - 별도의 체력(HP), 체력바, 회복 아이템은 사용하지 않는다.

2. **조작 방식**
   - 키보드: `A`/`D` 또는 좌우 방향키로 이동한다.
   - 마우스·터치: 화면의 가로 위치를 따라 군인이 좌우로 이동한다.
   - 마우스 클릭, 터치, `Space`로 위쪽을 향해 발사한다.
   - 모바일에는 왼쪽·오른쪽 이동 버튼과 사격 버튼만 제공한다.
   - 무기를 버튼이나 숫자키로 직접 선택하는 기능은 제공하지 않는다.
   - 기본 권총은 탄약이 무제한이며, 소총과 산탄총은 좀비 처치 시 떨어지는 아이템으로만 획득한다.
   - 무기 아이템은 아래로 이동하고 군인과 접촉하면 자동 획득되며, 전용 탄약을 모두 사용하면 기본 권총으로 돌아간다.

3. **적과 웨이브**
   - 일반형, 빠른형, 중장갑형 등 최소 3종의 좀비를 제공한다.
   - 모든 좀비의 기본 진행 방향은 위에서 아래다.
   - 좀비는 머리, 몸통, 팔, 다리가 구분되는 형태로 표현하고 이동 중 걷기 애니메이션을 재생한다.
   - 웨이브 전환 중에도 적 생성과 배경 스크롤은 멈추지 않는다.
   - 웨이브가 올라갈수록 생성 간격, 이동 속도, 체력이 증가한다.
   - 일정 웨이브마다 대형 보스를 등장시키되 보스도 화면 아래쪽을 향해 내려오게 한다.

4. **점수와 상태**
   - 좀비 처치 점수, 연속 처치 콤보, 웨이브를 HUD에 표시한다.
   - 최고 점수는 `localStorage`에 저장하고, 로그인 회원의 최고 기록은 Firebase 게임별 순위에도 저장한다.
   - 사이드바에 좀비 슈팅 Firebase `TOP 10` 순위를 표시한다.
   - 상태는 `idle → running → paused → over`로 관리한다.
   - 게임오버 오버레이에 최종 점수, 웨이브, 최고 점수와 다시 시작 버튼을 표시한다.

5. **기술 기준**
   - Phaser 3.90.0과 Arcade Physics의 Group 및 `overlap` 충돌을 사용한다.
   - 게임 내부 해상도는 모바일 세로 화면에 맞춘 `480×720`을 기본으로 사용한다.
   - 캔버스 id는 `gameCanvas`로 유지한다.
   - 화면 밖 총알과 처치된 좀비는 즉시 정리한다.
   - 사이드바에 `Powered by Phaser`와 공식 문서 링크를 표시한다.

6. **재미의 핵심 방향**
   - 플레이어가 계속 판단하도록 `어느 적을 먼저 쏠지`, `어느 아이템을 받으러 이동할지`, `콤보를 유지할지`를 핵심 선택으로 만든다.
   - 단순히 적의 체력과 속도만 높이지 않고 적 조합, 진입 대형, 이벤트 웨이브와 보스 패턴으로 난도를 변화시킨다.
   - 한 판은 처음 30초 안에 아이템 획득과 콤보 보상을 경험할 수 있어야 한다.
   - 군인과 좀비의 직접 충돌 한 번이 게임오버로 이어지는 규칙은 유지하되 피할 수 없는 배치나 경고 없는 돌진은 만들지 않는다.

7. **콤보와 오버드라이브**
   - 적을 `2.4초` 안에 연속 처치하면 콤보가 증가하고 점수 배율이 올라간다.
   - 콤보 `5`, `10`, `20` 달성 시 화면 효과와 짧은 음향으로 성취감을 제공한다.
   - 콤보 20을 달성하면 `5초` 동안 오버드라이브가 발동한다.
     - 권총 연사 속도 증가
     - 아이템 탄약을 소비하지 않음
     - 처치 점수 2배
   - 사격이 빗나가도 콤보는 유지하고, 일정 시간 적을 처치하지 못했을 때만 콤보를 초기화한다.

8. **아이템 드롭 확장**
   - 아이템은 모두 적 처치 지점에서 생성되어 화면 아래로 내려온다. 별도의 선택 메뉴에서 지급하지 않는다.
   - 무기 아이템:
     - `소총`: 빠른 연사, 80발
     - `산탄총`: 넓은 범위, 24발
     - `관통탄`: 일렬로 선 적을 관통, 30발
   - 전술 아이템:
     - `수류탄`: 획득 즉시 화면의 일반 좀비에게 큰 피해
     - `냉각탄`: 5초 동안 모든 적의 이동 속도 40% 감소
     - `자석`: 6초 동안 가까운 아이템을 군인 쪽으로 끌어당김
   - 아이템 운반 좀비는 머리 위에 상자 표시를 보여주고 처치 시 무기 아이템을 반드시 떨어뜨린다.
   - 동시에 여러 아이템이 내려오도록 해 안전한 위치와 필요한 아이템 중 하나를 선택하게 만든다.

9. **적 종류와 역할**
   - `일반 좀비`: 기본 속도와 체력으로 대형을 구성한다.
   - `달리기 좀비`: 빠르지만 체력이 낮고 등장 전에 해당 차선에 짧은 경고를 표시한다.
   - `중장갑 좀비`: 느리고 체력이 높으며 뒤의 빠른 적을 가리는 방패 역할을 한다.
   - `지그재그 좀비`: 내려오면서 좌우 차선을 한 번씩 변경해 조준을 방해한다.
   - `분열 좀비`: 처치하면 작은 좀비 2마리로 갈라지므로 화면 아래쪽에서 처치할수록 위험하다.
   - `아이템 운반 좀비`: 전투력은 낮지만 놓치고 싶지 않은 보상 목표가 된다.
   - 한 화면에 특수 적을 과도하게 겹치지 않고, 서로 다른 역할의 적은 최대 2~3종만 동시에 조합한다.

10. **웨이브와 이벤트 구성**
   - 기본 웨이브는 `18초`이며 웨이브가 바뀌어도 배경과 적 생성은 계속된다.
   - 매 웨이브 시작 시 `일반`, `돌진`, `중장갑`, `지그재그` 중 하나의 주제를 1초 동안 표시한다.
   - 3웨이브마다 아래 이벤트 중 하나를 무작위로 실행한다.
     - `보급 웨이브`: 아이템 운반 좀비가 여러 마리 등장
     - `떼거리 웨이브`: 약한 일반 좀비가 넓게 진입
     - `정예 웨이브`: 적 수는 적지만 중장갑과 특수 적 비율 증가
     - `야간 웨이브`: 시야가 좁아지지만 적의 눈과 아이템은 밝게 표시
   - 같은 이벤트가 연속해서 선택되지 않도록 직전 이벤트를 기억한다.
   - 웨이브 종료 시 게임을 멈추지 않고 `처치 수`, `최대 콤보`, `놓친 아이템`을 짧게 표시한다.

11. **보스전 기획**
   - 5웨이브마다 보스를 등장시키고 보스 등장 2초 전에 경고선과 진입 위치를 표시한다.
   - 보스도 계속 화면 아래쪽을 향해 내려오며 시간이 무한정 늘어지지 않게 한다.
   - 보스 패턴은 단계별로 추가한다.
     - 1단계: 좌우로 천천히 이동하며 일반 좀비 소환
     - 2단계: 체력 60% 이하에서 두 차례 빠르게 차선 변경
     - 3단계: 체력 25% 이하에서 이동 속도 증가
   - 공격 가능한 약점이 좌우로 이동하도록 만들어 군인의 위치 변경을 유도한다.
   - 보스 처치 시 산탄총 또는 관통탄 아이템을 반드시 떨어뜨리고 큰 점수 보너스를 지급한다.

12. **성장과 한 판의 변화**
   - 3웨이브를 통과할 때마다 게임을 잠깐 멈추고 무기 선택이 아닌 `공통 능력 강화` 3개 중 1개를 고르게 한다.
     - 기본 권총 공격력 +15%
     - 모든 총알 크기 +20%
     - 아이템 탄약 +25%
     - 콤보 유지 시간 +0.4초
     - 아이템 드롭 확률 +5%
   - 같은 강화는 최대 3단계까지만 중첩한다.
   - 강화 선택지는 현재 보유 단계와 효과를 명확히 표시하고 모바일에서도 큰 카드 버튼으로 제공한다.
   - 영구 능력치 구매는 우선 도입하지 않고, 매 판 다른 조합을 만드는 로그라이크식 성장에 집중한다.

13. **연출과 조작 감각**
   - 총알 명중 시 짧은 흰색 점멸, 처치 시 작은 파편, 강한 무기 사용 시 약한 화면 흔들림을 적용한다.
   - 아이템은 색상뿐 아니라 모양과 문자 아이콘으로도 구분해 색각에 의존하지 않는다.
   - 위험한 적과 보스 패턴은 붉은 차선 경고로 먼저 알려준다.
   - 콤보, 아이템 획득, 보스 등장에는 서로 다른 효과음을 사용하고 음소거 버튼을 제공한다.
   - 모바일 진동은 아이템 획득과 게임오버에만 짧게 사용하며 기기 지원 여부와 사용자 설정을 확인한다.
   - 게임 중 HUD는 점수, 웨이브, 콤보, 현재 무기와 탄약만 표시해 전투 화면을 가리지 않는다.

14. **난이도와 공정성 기준**
   - 첫 웨이브는 권총만으로 충분히 막을 수 있어야 하며 첫 특수 적은 조작을 익힌 뒤 등장시킨다.
   - 적의 최저 생성 간격과 화면 내 최대 수를 제한해 저사양 모바일에서도 피할 수 있는 상황을 유지한다.
   - 빠른 적이 군인 바로 위에 생성되거나 아이템과 겹쳐 판독이 어려운 상황을 금지한다.
   - 보스와 빠른 적이 동시에 군인 근처에 도착하는 조합은 만들지 않는다.
   - 평균 신규 플레이어가 3웨이브, 숙련 플레이어가 10웨이브 이상 도달하는 것을 1차 밸런스 목표로 삼는다.

15. **구현 우선순위**
   - `1차`: 아이템 운반 좀비, 관통탄, 수류탄, 콤보 단계 보상
   - `2차`: 지그재그·분열 좀비, 이벤트 웨이브, 보스 경고와 단계 패턴
   - `3차`: 3웨이브 강화 선택, 오버드라이브, 야간 웨이브
   - `4차`: 효과음·진동·접근성 옵션과 세부 밸런스 조정
   - 각 단계 완료 후 모바일 실제 기기에서 프레임 속도, 입력 지연, 아이템 판독성과 피할 수 없는 패턴 여부를 우선 검수한다.

16. **현재 구현 상태 (`2026-08-24`)**
   - 콤보 단계 알림, 콤보 20 오버드라이브와 점수 2배를 구현했다.
   - 소총, 산탄총, 관통탄, 수류탄, 냉각탄, 자석 아이템을 구현했다.
   - 일반, 달리기, 중장갑, 지그재그, 분열, 아이템 운반, 소형 좀비를 구현했다.
   - 일반, 돌진, 중장갑, 지그재그, 보급, 떼거리, 정예, 야간 웨이브를 구현했다.
   - 보스 진입 경고, 3단계 속도·차선 패턴, 일반 좀비 소환과 이동 약점을 구현했다.
   - 3웨이브 통과마다 공통 능력 강화 3개 중 하나를 선택하는 기능을 구현했다.
   - 명중·처치 파편, 화면 흔들림·점멸, 효과음·음소거와 모바일 진동을 구현했다.
