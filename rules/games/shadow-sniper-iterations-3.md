# 윌리 게임 추가 개선 21~30회

각 회차 구현 후 누적 규칙 검사 실행. UI 항목은 최종 실제 Chromium 검사로 확인.

21. 인물별 사교성에 따라 대화 시간이 달라지고 피곤한 인물은 대화를 미룸. 검사: 실제 대화 시간 차이와 피로 거절.
22. 최근 대화 상대 두 명을 30초간 기억해 같은 상대와의 반복 대화를 줄임. 검사: 양쪽 기억·만료·미션 초기화.
23. 독서가/과학자/운동선수/배달부의 관람 선호를 구분. 위험 반응 대기 중에는 관람을 시작하지 않음. 검사: 직업별 선호 및 위험 우선순위.
24. 휴식 시간을 피로량으로 계산하고 피로가 남으면 휴식을 이어감. 검사: 피로별 시간 차이·휴식 연장·총성 시 대피 우선.
25. 대각선 키보드 조준 속도 정규화와 집중 중 절반 속도 정밀 이동. 검사: 이동 거리·집중 속도·일시정지.
26. 스코프/재장전/탄창/관찰 조건에 따른 사격 준비 안내. 표적 정답은 공개하지 않음. 검사: 각 차단 조건의 안내.
27. 실제 명중 판정 후 사격 결과와 시간을 미션별 기록. 검사: 연출 전 비공개·건너뛰기 중복 방지·미션 초기화.
28. 15초 이하 시간, 경계도 72 이상, 전체 탄약 3발 이하 경고를 함께 표시. 검사: 복합 경고·일시정지 유지·종료 해제.
29. 굵은 흰색 조준선 옵션과 브라우저 저장. 검사: 실제 캔버스 픽셀 변화·재접속 유지.
30. 관찰한 외형 메모 검색과 필터 인원 표시. 검사: 부분 검색·공백 처리·미관찰 정보 비공개·검색 입력 중 사격 단축키 차단.

최종 검증: 기존 1~20회, 추가 21~30회, 여섯 맵/다중 시드 AI, 실제 Phaser 캠페인 및 모바일 입력 검사 통과. 공통 레이아웃·SEO와 새벽의 요새 규칙 검사 통과.
