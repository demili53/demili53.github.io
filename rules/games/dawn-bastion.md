# 새벽의 요새

- 메인 경로: `/`, 구현: `index.html`, 게임 ID: `dawn-bastion`. 이전 `/arcade/dawn-bastion.html`은 메인으로 이동합니다.
- Phaser 4.2.1, 720×720 Canvas. 캐릭터 아틀라스는 `assets/games/dawn-bastion/characters-v2.*`; 이미지 실패 시 자체 도형 사용.
- 방어전 10웨이브 / 돌격전 6웨이브 / 타워 전용 요새전 8웨이브. 모드별 보스와 로컬 기록을 유지합니다.
- WASD·방향키·모바일 드래그, 지점 클릭·B 건설 팝업, Q 충격파, P 일시정지. Esc는 팝업을 먼저 닫고, 팝업이 없으면 일시정지합니다. 보상 선택 중에는 전투를 정지합니다.
- 타워 6종·강화 카드·연속 처치·무피해 보너스를 유지합니다.
- 온라인 순위는 방어전만 집계하고 기존 기록 키와 이벤트 ID를 보존합니다.
- 비행기 게임은 `/arcade/space-shooter.html`에서 보조 게임으로 제공합니다.
- 검증: `node scripts/test-dawn-bastion.cjs`, `node scripts/test-site-layout.cjs`.

## 무기와 이펙트

- 타워 6종: 연사(60), 폭발(90), 냉기(75), 관통 광선(125), 연쇄 번개(110), 화염 방사(100). 공격 수치와 외형은 index.html의 TYPES 및 createTowerTextures에서 관리합니다.
- 광선은 선분 관통 판정, 번개는 110 거리 안의 서로 다른 3~5명에 25%씩 감쇠, 화염은 60~76도 부채꼴과 2초 연소(0.5초 간격)를 사용합니다.
- 연소 재적중은 남은 피해 주기를 보존합니다. 활성 연소는 더 강한 피해를 유지하고, 만료 후 새 연소는 현재 타워 수치를 사용합니다.
- 무기 효과는 전투 시간으로 움직이며 일시정지·보상 선택 중 정지합니다. 건설 팝업 중에는 전투·이동·이펙트가 계속 진행됩니다. 표시 효과는 100개, 피해 숫자는 18개로 제한하고 무기 본체 효과를 우선 유지합니다.
- 이펙트 줄이기 설정은 로컬 저장하며 OS의 동작 줄이기 설정도 따릅니다.
- 추가 무기 연출: 광선 이중 나선·렌즈 링, 가지 번개·방전 잔광, 폭발 충격파·탄도 불꽃·연기, 냉기 눈꽃, 화염 불티, 보스 처치 확산광. 광선·번개·냉기 타워에는 충전 문양과 수렴 입자가 있습니다.
- 추가 연출은 drawWeaponSpectacle에서 프레임당 최대 12개 효과에 적용합니다. 별도 파티클 객체·타이머 없이 효과 수명과 전투 시간만 사용하며 동작 줄이기에서는 생략합니다. 전체 화면 점멸과 카메라 흔들림은 사용하지 않습니다.
- 실제 브라우저 검증: scripts/test-dawn-bastion-browser.cjs. 일시정지 중 Canvas 이미지가 시간 경과에도 동일한지 확인하며 FX_SCREENSHOT 환경변수로 전투 및 폭발 장면을 저장할 수 있습니다.

- 건설 팝업은 클릭한 지점 옆에 표시하며 화면 가장자리에서 위치·높이를 제한합니다. 에테르와 구매 가능 상태는 전투 중 갱신합니다. 외부 클릭·닫기·Esc로 닫으며 웨이브 보상·패배·일시정지 시 자동으로 닫힙니다. 보상 선택 후 다음 웨이브가 즉시 진행됩니다.
