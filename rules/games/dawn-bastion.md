# 새벽의 요새

- 경로: `/arcade/dawn-bastion.html`, 게임 ID: `dawn-bastion`
- PixiJS 8.20.0, 내부 해상도 720 × 720. 외부 이미지 없이 자체 도형으로 만든 스프라이트 사용.
- WASD / 방향키 또는 터치 드래그로 이동. 가까운 적을 자동 공격.
- B로 건설 모드: 전투 시간을 멈추고 8개 고정 지점에 타워 설치. 번호 버튼 또는 전장 클릭으로 선택.
- 연사탑 60 / 폭발탑 90 / 냉기탑 75 에테르. 최대 3레벨. 강화 비용은 기본 비용 × 현재 레벨.
- 철거 시 누적 비용 60% 반환. 수정 수리는 60 에테르에 내구도 90 회복.
- 적 처치 시 에테르·점수 지급 및 자동 레벨 성장. 성장 시 공격력·연사력 증가와 체력 회복.
- 적은 중앙 수정을 공격하며, 가까운 플레이어를 추격. 수정 또는 플레이어 체력이 0이면 패배.
- 각 웨이브는 최소 28초, 모든 적 처치 후 진행. 4·7·10 웨이브 보스. 10웨이브 완료 시 승리.
- P / Esc 및 창 전환 시 일시정지. 재개는 명시적으로 선택.
- 로컬 최고 점수 키 `dawnBastionBest`. 종료 시 `partygame:score` 이벤트와 공통 Firebase 랭킹 연동.
- 온라인 기록을 허용하려면 `dawn-bastion`이 포함된 최신 `firestore.rules`를 배포해야 한다. 로그인 없이도 게임과 로컬 기록 사용 가능.
- 검증: `node scripts/test-dawn-bastion.cjs`.
