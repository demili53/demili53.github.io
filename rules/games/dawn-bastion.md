
# 랜덤타워디펜스 (랜덤 합성 디펜스)

- 메인 경로: `/`, 구현: `index.html`, 게임 ID: `dawn-bastion`. 이전 `/arcade/dawn-bastion.html`은 메인으로 이동합니다.
- 2026-11-20에 코드를 전부 걷어내고 새로 만들었습니다. Phaser를 쓰지 않고 Canvas 2D로 직접 그립니다. 예전 `BastionGame`·`MergeGame`과 `scripts/bastion-*.js`는 더 이상 없습니다(이전 코드는 git 기록에 있음).

## 파일

| 파일 | 역할 |
| --- | --- |
| `scripts/dawn-core.js` | 규칙 엔진. 화면과 무관한 순수 로직이며 Node와 브라우저에서 같은 파일을 씁니다(`Dawn`). |
| `scripts/dawn-art.js` | 전장 배경, 타워, 적 스프라이트를 캔버스에 미리 그립니다(`DawnArt`). |
| `scripts/dawn-view.js` | 엔진 상태를 그리는 렌더러와 전투 효과(`DawnView`). 규칙은 건드리지 않습니다. |
| `scripts/dawn-sound.js` | 합성 효과음(`DawnSound`). 설정에서 켰을 때만 소리 냅니다. |
| `index.html`의 `<script id="gameLogic">` | 버튼·포인터·키보드·오버레이·기록 저장. |
| `assets/games/dawn-bastion/characters-v2.*` | 적 원화 아틀라스. 불러오지 못하면 `dawn-art.js`가 도형으로 대신 그립니다. |

스크립트 주소의 `?v=` 값은 파일을 고칠 때 올립니다.

## 규칙 (`dawn-core.js`)

- 좌표계 720×720. 적은 왼쪽 위 차원문에서 나와 광장을 둘러싼 길(`TRACK`)을 시계 방향으로 한 바퀴 돌아 새벽 수정(`CORE`)에 닿습니다.
- 칸 25개(5×5, `GRID`·`PITCH` 96·`CELLS`). 2026-11-20에 4×4에서 세분화했습니다. 바깥 고리 16칸은 길에서 106, 안쪽 고리 8칸은 202, 한가운데는 298 떨어져 있습니다. 냉기탑·화염탑·가시탑은 바깥 고리에서만, 한가운데는 저격탑·별빛탑만 길에 닿습니다. 타워 그림은 `TOWER_SCALE`(0.8)로 줄여 그립니다. `reaches(index)`가 거짓이면 화면에 빨간 느낌표를 붙입니다.
- 소환 `summon()`: 20 에테르에서 시작해 소환마다 +4. 빈 칸 하나에 7종 중 하나가 무작위로 나옵니다. 10% 고급, 2% 희귀(행운의 부적으로 증가).
- 놓기 `drop(from,to)`: 같은 종류·같은 등급이면 한 등급 높은 무작위 종류로 합성, 빈 칸이면 이동, 다른 타워면 자리 교환. 등급 6단계(일반·고급·희귀·영웅·전설·신화).
- 능력치 `towerStats`: 피해 ×2.15^(등급−1), 사거리 +6/등급, 공격 간격 ×0.96^(등급−1).
- 타워: 연사탑(단일), 폭발탑(범위), 냉기탑(주변 둔화 2초), 번개탑(연쇄), 광선탑(직선 관통), 맹독탑(중독 3초, 재생·치유 차단), 화염탑(부채꼴 연소 2초). 연소와 둔화가 겹친 적은 열충격으로 피해 +25%.
- 판매 10×2^(등급−1). 화력 강화 `amplify()`: 120에서 시작해 +60씩, 모든 타워 공격력 +6%.
- 새벽 섬광 `flash()`: 30초 대기. 모든 적에게 최대 체력 12%(군주 4%) 피해와 2.5초 둔화.
- 수정 내구도 20. 보통 적 1, 중갑병·광전사·방벽 수호병 2, 군주 10. 0이면 패배.
- 웨이브: 무한. 출현 수 8+웨이브×2, 적 체력 (30+웨이브×10)×종류 배율×1.13^(웨이브−1), 군주 (240+웨이브×55)×같은 배율. 전멸하면 바로, 아니면 마지막 출현 6초 뒤에 다음 웨이브가 겹쳐 시작합니다. 군주 웨이브는 군주를 잡아야 넘어갑니다.
- 적 합류: 3 질주자, 4 중갑병, 6 재생술사·분열체, 8 광전사·망령, 11 방벽 수호병·치유 사제, 13 은신 추적자.
- 군주(5웨이브마다 순환): 소환(5초마다 병사 2), 철벽(체력 50% 보호막, 3초 안 맞으면 재생), 교란(7초마다 가까운 타워 3초 마비). 물리치면 강화 카드 3장 중 1장(화력·장전·조준·행운·복구·보급·공명)을 고르고 전장이 숲→협곡→빙하→습지→화산→유적으로 바뀝니다.
- 기록: `dawnMergeBest`(점수), `dawnMergeWave`(최고 웨이브). 패배 시 `partygame:score` 이벤트로 온라인 순위에 점수를 보냅니다.

## 타워 다양성과 업그레이드 (2026-11-20 5회 개선)

- 타워 12종: 기존 7종에 저격탑(가장 튼튼한 적 즉시 타격), 중력탑(적을 길 뒤로 밀어냄), 지휘탑(공격하지 않고 이웃 8칸 타워 공격력 +10%+등급×6%, 가장 강한 하나만 적용), 별빛탑(사거리 제한 없이 무작위 적에게 유성), 가시탑(사거리 안 길 위에 덫을 3개까지 설치)을 더했습니다.
- 종류가 늘어도 합성이 막히지 않도록 `rollType`이 40% 확률로 같은 등급의 기존 타워와 같은 종류를 냅니다. 공격 타워가 2개 미만이면 지휘탑은 나오지 않습니다.
- 연구 `study(type)`: 종류별 5단계(내부 값 0~4), 비용 50·100·150·200, 단계마다 공격력 +12%. 3단계와 5단계 능력은 `RESEARCH` 표에 있고 `knows(type, 단계)`로 확인합니다.
- 각성: 등급 5(전설) 이상이면 `AWAKEN` 표의 능력이 켜집니다(삼연사, 집속탄, 혹한, 과부하, 쌍광선, 부식, 불바다, 관통탄, 특이점, 전장 지휘, 유성우, 폭발 덫).
- 단련 `temper(index)`: 타워 하나에 별 3개까지, 별마다 공격력 +25%, 비용 30×1.8^(등급−1)×(별+1). 합성하면 높은 쪽 별을 물려받고 판매하면 절반을 돌려받습니다.
- 조합 반응 `REACTIONS`: 열충격(연소+둔화, 모든 피해 ×1.25), 감전(중독+번개 ×1.3), 파쇄(둔화·정지+폭발 ×1.3), 인화(중독+화염, 연소 피해 ×1.5), 급소(둔화·정지+저격 ×1.4). 같은 적에게는 1초에 한 번만 글자를 띄웁니다.
- 새 상태: `stun`(정지), `deep`(혹한), `acid`(부식), `zones`(불바다), `traps`(덫).
- 이펙트: 총구 섬광, 폭발 그을음 자국, 포탄 연기, 치명타 숫자, 빙결 얼음, 처형 표시, 중력 우물, 유성 낙하, 덫, 지휘 빛줄, 각성 고리, 등급이 높을수록 커지는 폭발·광선·번개.

## 화면

- 상단 HUD(웨이브·에테르·점수·수정), 웨이브 안내 줄(전장·남은 적·다음 군주), 전장, 버튼 3개(소환·화력 강화·새벽 섬광), 보조 줄(선택 정보·단련·판매·연구·배속·일시정지·설정). 연구 화면을 여는 동안 전투가 멈춥니다.
- 조작: 끌어서 놓기, 또는 타워를 누른 뒤 같은 타워나 빈 칸 누르기. Space 소환, A 강화, Q 섬광, X 판매, T 단련, R 연구, F 배속, P·Esc 일시정지.
- 캔버스는 표시 크기×기기 픽셀 비율(최대 2배)로 그려 고해상도 화면에서도 선명합니다.
- 페이지 전용 클래스는 `mg-` 접두사를 씁니다. `styles/site-design.css`가 `.shell .layout` 같은 이름을 꾸미기 때문에 그 이름을 다시 쓰지 않습니다.
- 이펙트 줄이기와 OS 동작 줄이기 설정을 따릅니다(입자·화면 흔들림·피해 숫자 생략).
