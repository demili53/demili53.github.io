- 메인 경로: `/`, 구현: `index.html`, 게임 ID: `dawn-bastion`. 이전 `/arcade/dawn-bastion.html`은 메인으로 이동합니다.
- Phaser 4.2.1, 720×720 Canvas. 캐릭터 아틀라스는 `assets/games/dawn-bastion/characters-v2.*`; 이미지 실패 시 자체 도형 사용.
- 2026-11-20에 기존 방어전·돌격전·요새전·원정·심연전 화면을 랜덤 합성 디펜스 한 가지 방식으로 바꿨습니다. 이전 화면은 git 기록에 있습니다.

## 규칙 (`MergeGame`, index.html의 gameLogic)

- `MergeGame`은 기존 `BastionGame`을 상속해 적 생성·무기 판정·보스 능력·이펙트 풀을 그대로 씁니다. `BastionGame`의 규칙을 바꾸면 합성 게임 전투도 바뀝니다.
- 칸 16개: 사분면마다 2×2(중심에서 ±74, ±140). 수호자 이동과 개인 공격은 없습니다.
- 소환: 20 에테르에서 시작해 소환마다 +4. 빈 칸 하나에 `MERGE.deck` 7종(연사·폭발·냉기·번개·광선·맹독·화염) 중 하나가 무작위로 나옵니다. 10% 고급, 2% 희귀로 바로 나옵니다.
- 합성 `drop(from,to)`: 같은 종류·같은 등급이면 한 등급 높은 무작위 종류로 합성, 빈 칸이면 이동, 다른 타워면 자리 교환. 등급은 6단계(일반·고급·희귀·영웅·전설·신화)이고 최고 등급은 합성하지 않습니다.
- 등급 수치 `towerStats`: 피해 ×2.15^(등급−1), 사거리 +8, 공격 간격 ×0.96^(등급−1). 폭발 반경·연쇄 수·광선 폭·화염 각도는 기존 레벨 공식에 등급을 넣어 계산합니다.
- 판매: 10×2^(등급−1) 에테르. 화력 강화: 120 에테르에서 시작해 구매마다 +60, 모든 타워 공격력 +6%(`perks.overcharge`).
- 웨이브: 무한. 적 체력 ×1.13^(웨이브−1), 출현 수 8+웨이브×2, 적 구성은 `abyssRoster()`. 5웨이브마다 소환·철벽·교란 군주가 순환합니다.
- 군주 웨이브를 넘기면 강화 카드 3장 중 1장(화력·장전·조준·복구·보급·공명)을 고르고 전장이 숲→협곡→빙하→습지→화산→유적 순으로 바뀝니다. 일반 웨이브는 멈추지 않고 이어집니다.
- 충격파(Q)만 스킬로 남겼습니다. 수정 내구도 300, 웨이브마다 +15 회복.
- 기록: `dawnMergeBest`(점수), `dawnMergeWave`(최고 웨이브). 패배 시 `partygame:score` 이벤트로 온라인 순위에 점수를 보냅니다. 이전 방식의 순위 기록과 같은 목록을 씁니다.

## 화면

- 상단 HUD(웨이브·에테르·점수·수정), 전장, 버튼 3개(소환·화력 강화·충격파), 보조 줄(선택 정보·판매·배속·일시정지·설정). 준비 화면의 선택 상자와 사이드 패널은 없앴습니다.
- 조작: 끌어서 놓기, 또는 타워를 누른 뒤 같은 타워나 빈 칸 누르기. Space/S 소환, A 강화, Q 충격파, X 판매, P·Esc 일시정지, 보상 중 1·2·3.
- 페이지 전용 클래스는 `mg-` 접두사를 씁니다. `styles/site-design.css`가 `.shell .layout` 같은 예전 클래스를 꾸미기 때문에 그 이름을 다시 쓰지 않습니다.

## 그래픽

- `scripts/bastion-lighting.js`: 캔버스 그라디언트 텍스처로 만든 가산 혼합 빛(수정·타워·군주·포탄·폭발), 가장자리 비네트, 밤에서 새벽으로 바뀌는 색조, 진입로 차원문. 5웨이브 구간 안에서 점점 밝아지고 군주를 넘기면 다시 밤이 됩니다. 빛은 프레임당 층별 40개로 제한합니다.
- 등급 표현: 칸 테두리와 마름모 표식이 등급 색을 따르고, 영웅 이상은 회전 호, 전설 이상은 추가 광원이 붙습니다. 소환·합성 시 튀어나오는 크기 연출과 `levelup`·`shockwave` 이펙트를 씁니다.
- 합성 가능한 타워는 고리가 깜빡이며(설정에서 끌 수 있음), 끄는 동안 합성 대상이 밝게 표시됩니다.
- 모든 연출은 전투 시간(`game.time`)만 사용해 일시정지·보상 선택 중 멈춥니다. 이펙트 줄이기와 OS 동작 줄이기 설정을 따릅니다.
- 지형·적·타워 텍스처는 `scripts/bastion-graphics.js`와 index.html의 `createTowerTextures`, `createCharacterTextures`, `drawCombatEffects`를 그대로 씁니다.

## 검증

- `node scripts/test-dawn-merge.cjs`: 합성 게임 규칙과 봇 밸런스 범위(12~45웨이브 사이 종료).
- `node scripts/test-dawn-bastion.cjs`: 상속받는 `BastionGame` 전투 규칙 회귀.
- `node scripts/test-dawn-bastion-browser.cjs`(Playwright): 단순화된 화면, 소환, 끌기·누르기 합성, 이동, 판매, 강화, 일시정지 정지 화면, 군주 보상, 전장 전환, 기록 저장, 모바일 배치.
- bastion-*.js 주소의 `?v=` 값은 스크립트를 고칠 때 올립니다.
- 더 이상 페이지에서 쓰지 않는 파일: `scripts/bastion-progress.js`, `scripts/bastion-convenience.js`와 그 테스트. 지워도 됩니다.
