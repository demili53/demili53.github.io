# 윌리 저격게임 개선 10회 · 2026-11-12

각 회차는 변경 후 누적 회귀 검사 `node scripts/test-shadow-sniper-improvements.cjs`를 실행한다. 전체 캠페인·브라우저 검사는 마지막에 실행한다.

1. 입력 안정성: 잘못된 좌표·시간 값과 0초 업데이트를 무시하여 조준·AI 상태 오염 방지. 검증: 입력 전후 게임 상태가 같고 정상 좌표 제한이 유지됨.
2. 경로 연결: 다음 경유지 너머가 보이면 불필요한 모서리를 건너뛰어 멈칫거림 감소. 검증: 열린 길은 단축되고 가구를 가로지르는 단축은 거부됨.
3. 사회 행동: 양쪽 모두 경계가 풀렸을 때만 대화하고, 상대를 바라보며 관계가 끊기면 종료. 검증: 경계 중인 상대에게 대화를 강제하지 않으며 중복 대화·사망한 상대와의 대화 방지.
4. 관람 관리: 공연자·작업자가 자리를 떠나면 관람 장소와 예약을 즉시 해제. 검증: 빈자리를 향한 방문 방지와 진행 중 예약 정리.
5. 관찰 편의: 0.22초 이내 조준 이탈은 진행도를 유지하고 확인을 마친 인물은 해당 미션 동안 기억. 보이지 않는 인물 정보는 표시하지 않음. 검증: 짧은 이탈·다른 인물 전환·재관찰·미션 초기화.
6. 연출 건너뛰기: 총알 연출 도중 버튼으로 즉시 결과 확인. 검증: 명중·빗나감은 한 번만 처리되고 일시정지 중에는 건너뛰기 차단.
7. 결과 요약: 미션별 S/A/B 평가, 발사 수·정확도·관찰 인원·소요 시간을 표시. 기존 점수 계산 유지. 검증: 미션별 집계 분리와 결과 중복 기록 방지.
8. 화면 효과 설정: OS 동작 줄이기를 기본값으로 사용하고 사용자의 선택을 저장. 눈·카메라 줌 이동·촬영 점멸·총알 장식·입자를 줄이되 게임 시간과 판정은 유지. 검증: 브라우저에서 체크박스 상태와 설정 저장·해제를 확인.
9. 키보드 조작: 버튼에 포커스가 있을 때 Space/Enter의 기본 동작을 유지하고 입력·편집 영역에서는 게임 단축키를 차단. 연출 건너뛰기 후 전장으로 포커스 복귀. 검증: Space로 스코프·체크박스를 각각 한 번만 전환하고 건너뛰기 후 결과·포커스 확인.
10. 맵 분위기: 식물원 나비, 항구·해변 물결 반사, 축제 전구, 중앙역 신호등 애니메이션 추가. 맵당 최대 12개로 제한하고 게임 시간을 사용해 일시정지·총알 연출 때 정지. 효과 줄이기 설정에서는 생략. 검증: 결정적 좌표·개수 제한·설정·정지와 여섯 맵 실화면 회귀 검사.
