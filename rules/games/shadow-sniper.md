# 윌리를 찾아서 저격해라

- 페이지 `/arcade/shadow-sniper.html`, 게임 ID `shadow-sniper`, Phaser 4.2.1, 960 × 540.
- 각 장소의 군중 속에서 외형 단서를 조합해 윌리를 식별. 다른 인물 오인 사격 시 실패.
- 6개 미션: 항구 시장 27명, 별빛 축제 44명, 눈꽃 산장 마을 52명, 식물원 48명, 노을 해변 산책로 52명, 중앙역 56명. 군중 역할 21종과 윌리로 구성. 윌리의 위치는 매 도전마다 다른 인물과 교환하여 무작위 배치.
- 추가 역할 8종: 정원사(물주기), 독서가(책장 넘기기), 낚시꾼(낚싯대·찌), 풍선 상인(줄과 흔들리는 풍선), 과학자(확대경 관찰), 운동선수(스트레칭), 드러머(북 연주), 제빵사(반죽). 모자·복장·소품 및 팔·몸 동작을 구분하며 일시정지·사격 연출 중 함께 정지.
- 식물원은 유리 온실·나무·화단, 해변은 노을·바다·범선·목재 산책로, 중앙역은 철골 지붕·열차·시계·승강장으로 구분. 신규 맵의 화단·벤치는 렌더링과 AI 경로 탐색이 같은 장애물 좌표를 사용.
- 모든 인물은 장소·직업에 맞는 행동을 수행. 항구에서는 짐 운반·요리·장보기·사진 촬영, 축제에서는 춤·연주·박수·저글링, 눈꽃 마을에서는 스키·스케이트·제설·눈사람 만들기. 팔·다리·몸 기울기와 소품을 함께 움직이고 인물마다 동작 시차를 둠. 이동 위치는 명중 판정과 공유하며 활동과 소품 애니메이션은 일시정지·총알 추적 중 함께 정지.
- 군중 AI는 직업 활동 → 목적지 이동 → 주변 관찰/인사 → 활동을 반복. 작업자는 작업 위치를 유지하고 이동자는 각자의 구역에서 무작위 목적지를 선택. 가속·감속, 이웃 회피, 탁자·화분·벤치 회피를 적용하며 막히면 대기 후 다시 행동. 걸음은 실제 이동 거리에 동기화하고 자세 전환을 보간.
- 시설 모서리의 이동 지점을 연결해 짧은 우회 경로를 탐색하고, 이동 중 막히면 최대 두 번 재탐색. 작업 위치는 시작 시 시설 밖으로 보정해 복귀 목적지가 시설 안에 남지 않게 함. 걸을 때 번갈아 발을 들고, 달릴 때 몸을 더 기울이며, 대기 중에는 미세한 호흡 동작을 적용.
- 여유 있는 이동 인물끼리 가까이 만나면 잠시 서로를 바라보며 대화하고 말풍선을 번갈아 표시. 대화 뒤 재대화 대기 시간이 있으며, 총성이 들리면 관계를 해제하고 대피. 표적도 동일한 사회 행동 규칙을 사용.
- 빗나간 총알에 거리와 개인차에 따라 순차적으로 놀람 → 대피 → 주변 확인 → 원래 구역 복귀. 총알 연출이 끝난 뒤 반응 시간이 흐르며 일시정지 중에는 모든 AI 타이머도 정지. 스코프 위치 자체에는 반응하지 않음.
- 위험 기억은 총알 위치·거리·누적 불안에 따라 생성되고 시간이 지나면 감소. 대피 목적지는 위협에서 멀어지는 정도와 주변 혼잡도를 함께 평가하며, 불안이 남아 있으면 대화를 미루고 이동 속도를 높임.
- 상대 속도로 최대 1.6초 뒤 접근을 예측해 충돌 전에 한쪽이 감속·양보. 가까운 거리 회피와 같은 방향으로 비켜서며, 정지한 인물에는 이동자가 양보. 정체는 이동량뿐 아니라 다음 경유지까지 거리가 줄어드는지로 판단하여 제자리 선회도 감지.
- 짧은 시간 안에 총성이 반복되면 경계 시간이 길어지고, 복귀 뒤에도 잠시 주변을 살핌. 시선 방향과 달리기 강도를 부드럽게 전환하며 모든 관련 타이머는 일시정지·총알 연출 중 정지. 대화 상대가 숨거나 사라지면 대화를 종료.
- 이동 인물은 가까운 연주·그림·요리·눈사람 활동을 목적지로 선택. 장소마다 좌우 두 관람 위치를 예약하고, 혼잡·거리·직전 방문지를 고려해 다른 목적지를 선택. 도착 후 카메라 보유자는 촬영, 연주 관람자는 박수, 나머지는 구경. 총성·주최자 이탈·방문 종료 시 예약 해제.
- 실제 이동량에 따른 피로를 누적하고 속도를 최대 22% 낮춤. 안전한 상황에서 피로가 높으면 잠시 쉬며 회복하고, 위험 반응이 휴식보다 우선. 휴식 자세·피로·방문 예약은 일시정지와 사격 연출 중 함께 정지.
- 명중·관찰 판정은 몸 기울기와 상하 움직임을 반영하며 인물이 겹치면 화면 앞쪽 인물을 우선 판정.
- 관찰은 0.22초 이내 조준 이탈에 진행도를 유지하고, 확인을 마친 인물은 미션 동안 기억. HUD에 관찰 기록 인원 표시. 다른 미션·재도전 시 초기화.
- 결과 화면에 이번 미션의 발사 수·정확도·관찰 인원·소요 시간과 S/A/B 평가를 표시. 첫발 명중이면서 제한시간 절반 이상 남으면 S, 첫발 명중은 A, 그 외 성공은 B. 평가 자체는 기존 점수를 변경하지 않음.
- 빨강·흰 줄무늬 + 빨간 털모자 + 둥근 안경 공통 단서에 장소별로 검은 가방 / 노란 스카프 / 초록 스카프를 조합. 눈꽃 마을에서 윌리는 주기적으로 가림막 뒤에 숨음.
- 식물원은 파란 스카프, 해변은 보라 스카프, 중앙역은 주황 스카프가 추가 식별 단서. 여섯 번째 미션 성공 시 캠페인을 완료하며 HUD와 미션 진행 표시가 미션 수를 따름.
- 발사 시 `shot` 상태로 전환: 1.05초 총알 추적 → 명중 판정·혈흔 입자·몸 회전으로 넘어짐 → 2.45초 후 원래 전투 또는 결과 상태. 사격 연출 중 작전 시간·인물 이동·추가 사격·재장전·조준 입력을 중지하며, 일시정지와 창 전환 시 연출도 정지.
- 사격 연출 중 '연출 건너뛰기'로 결과를 즉시 확인할 수 있음. 판정·점수·결과 기록은 한 번만 처리하고 일시정지 중에는 차단.
- 화면 효과 줄이기는 OS 설정을 기본값으로 사용하고 `shadowSniperReducedMotion`에 사용자 선택 저장. 배경 장식·눈·촬영 점멸·총알 장식·혈흔 입자·카메라 줌 이동을 줄이며 이동·판정은 유지. 나비·물결 반사·전구·신호등은 맵당 최대 12개, 게임 시간으로만 갱신.
- 혈흔 입자는 최대 18개이며 수명이 끝나면 제거. 쓰러진 인물은 다시 이동하거나 보상을 중복 지급하지 않음.
- 마우스 / 터치 드래그 / 방향키로 조준. Space / 우클릭 / 버튼으로 스코프. F / 스코프에서 클릭 / 사격 버튼으로 발사.
- Shift 누르기 또는 집중 버튼으로 흔들림 감소. 집중력은 소진 후 자동 회복.
- R / 재장전 버튼으로 1.6초 재장전. 탄창 3발 + 예비 9발. P / Esc 일시정지; 창 전환 시 자동 일시정지.
