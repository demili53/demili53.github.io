# 윌리 게임 추가 개선 31~40회

31. 호기심에 따른 탐색 거리: 인물마다 평상시 이동 반경을 다르게 적용. 대피 거리와 기존 이동 경계는 유지.
32. 자연스러운 대화 종료: 서로 멀어지거나 시설에 가려지면 양쪽 대화 관계 해제.
33. 대체 목적지 탐색: 가장 선호하는 목적지로 갈 수 없으면 다음 후보의 도달 가능성을 확인.
34. 위험한 작업장 복귀 지연: 기억 중인 총알 위치가 작업장 가까이에 있고 현재 위치가 더 안전하면 불안이 줄 때까지 기다림.
35. 전체화면: 게임 패널과 조작 버튼을 함께 확대하며 종료 버튼 제공. 미지원 브라우저에서는 숨김, 거부 시 안내.
36. 왼손 사격 배치: 사격 버튼을 왼쪽으로 옮기고 설정 저장. 실제 DOM 순서를 바꾸어 시각·키보드 순서 일치.
37. 수동 단서 체크: 외형 단서를 직접 체크하고 확인 개수 표시. 자동 정답 판별이나 점수 변화 없음. 새 미션/재도전 시 초기화.
38. 관찰 메모 고정: 관찰한 외형만 고정해 검색 중에도 비교 가능. 현재 좌표나 정답을 공개하지 않으며 새 미션/재도전 시 초기화.
39. 조작 도움말: 버튼으로 설명을 열면 작전을 일시정지. 대화상자 내 단축키가 게임으로 전달되지 않고 닫은 뒤 명시적으로 계속하기.
40. 선택형 효과음: 사격·명중·재장전·미션 결과를 짧은 합성음으로 구분. 매 방문 기본 무음, 사용자 조작 시 활성화, 음량 저장. 일시정지/숨김/음소거와 동시 재생 제한 지원.

검사: 누적 1~30회 및 31~34회 코어 검사, 여섯 맵/다중 시드 AI 검사, 효과음 단위 검사. 35~40회 UI는 실제 Chromium 전체화면·터치·키보드·저장·포커스·모바일 화면 검사로 검증.
